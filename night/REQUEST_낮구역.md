# 낮 구역 선생님께 요청 (밤 구역 → 낮 구역)

밤 구역 작업은 낮 파일을 고치지 않고 끝냈어요. 아래는 **있으면 더 좋은 것**들이에요. 반영하지 않아도 밤 구역은 지금 그대로 작동해요.

## 1. 낮 스토리 영상 첫 문장 (순서 문제 · 1-1 A)
- 지금: "지난밤 연구원들이 바이오 트윈을 재가동했지만…" → **낮을 먼저 하는 모둠**에게는 아직 일어나지 않은 일이에요.
- 제안 (순서와 상관없이 통하는 문장):
  > "바이오 랩은 낮과 밤, 두 구역이 함께 돌아가요. 지금 낮 구역의 광합성 장치가 멈췄어요."
- 밤 스토리 영상은 이미 순서와 상관없게 써 두었어요 ("낮 구역에서는 잎이 당을 만들어요…").

## 3. 배경음악 (1-1 G)
- ✅ 밤 배경음(`night/assets/bgm_night.mp3`)은 밤 구역이 직접 틀어요: 스토리 영상 '혈당 경보'가 끝나면 시작 → 작전 설명 → 밤의 온실 → LOCK 화면까지 이어지고, 🔊 음소거를 따라요. 처음 화면으로 가면 멈춰요.
- 밤 온실 화면에도 배경음악이 있으면 좋겠어요. `sound.js`에 밤 테마를 추가해 주세요.
  - 화면: 밤 온실(장치 고르는 화면)
  - 분위기: 조용한 관제실, 느린 신스 패드 + 작은 반짝임(별), 템포 70~80, 단조 느낌이지만 무섭지 않게
  - 음량: 낮 온실 음악보다 조금 작게

## 4. 교사용 대시보드
- ✅ **이미 넣었어요 (app.js `[NIGHT]` 2줄)**: 모둠 카드 아래 밤 칸 — 밤 점수(최고 100점)·LOCK·보너스·힌트·오답, **실천 서약 목록과 [✅ 실천 서약 승인] 버튼**. 학생이 서약을 내면 카드가 노랗게 깜박이고, 선생님이 승인하면 학생 태블릿의 승인 패드가 저절로 열려요. (원래 나이트 미션의 핵심 장면이라 꼭 필요해요)
- 🙏 부탁: 구역 줄(zoneRow)의 밤 칸이 지금 ●로만 나와요. 밤 칸 아이콘을 LOCK 4 📦 · LOCK 5 ⚖️ · LOCK 6 🩺 · LOCK 7 🛡️ · LOCK 8 📝 · 보너스 🤲 순서로 보여 주세요. 미션 키 순서는 `cargo, energy, twin, protocol, plan` + 보너스 `warmth`예요.
- 🙏 부탁: 카드 맨 아래 🏅 점수가 낮 점수만이에요. 낮·밤을 나눠 "☀️ ○점 · 🌙 ○점"으로 보이면 좋겠어요. 밤 점수는 `NZ.nightScore(team).total`.
- 🙏 부탁: 위쪽 요약 칸에 "🔔 서약 승인 대기 ○모둠"이 있으면 좋겠어요. 조건: `t.night.approvalRequested && !t.night.checkpoint?.plan`
- 명예의 전당에 밤 게임을 넣는다면: 키 `warmth`, 이름 '모두의 온기'

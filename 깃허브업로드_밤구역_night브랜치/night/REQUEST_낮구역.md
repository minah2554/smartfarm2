# 낮 구역 선생님께 요청 (밤 구역 → 낮 구역)

밤 구역 작업은 낮 파일을 고치지 않고 끝냈어요. 아래는 **있으면 더 좋은 것**들이에요. 반영하지 않아도 밤 구역은 지금 그대로 작동해요.

## 1. 낮 스토리 영상 첫 문장 (순서 문제 · 1-1 A)
- 지금: "지난밤 연구원들이 바이오 트윈을 재가동했지만…" → **낮을 먼저 하는 모둠**에게는 아직 일어나지 않은 일이에요.
- 제안 (순서와 상관없이 통하는 문장):
  > "바이오 랩은 낮과 밤, 두 구역이 함께 돌아가요. 지금 낮 구역의 광합성 장치가 멈췄어요."
- 밤 스토리 영상은 이미 순서와 상관없게 써 두었어요 ("낮 구역에서는 잎이 당을 만들어요…").

## 2. 작전 설명(브리핑) 문구
| 장 | 위치 | 지금 | 바꾸고 싶은 문구 |
|---|---|---|---|
| 1장 | `journey` 밤 칸 3개 | 체관 / 가공 공장 / 바이오 트윈 | 그대로 좋아요 ✅ |
| 3장 | 밤 구역 상황 | "22:00, 나이트 모드. …" | 그대로 좋아요 ✅ |
| 4장 | `split.night` | "관제 AI 플로의 안내에 따라 … 06:00 해가 뜨기 전에 바이오 트윈을 재가동하라." | 그대로 좋아요 ✅ (LOCK 4~8, 다섯 글자 조각, 재가동 명령어가 모두 실제 밤 화면과 같아요) |
| 5장 | 작전 개시 | "…보너스 게임까지 모두 해결해야 식물에 이름을 붙이고 기념사진을 받을 수 있다." | 낮·밤 공통으로: "…보너스 게임까지 모두 해결하면 구역 완전 복구 인증서를 받는다." (밤은 식물 이름표 대신 '밤 구역 완전 복구' 인증서예요) |

## 3. 배경음악 (1-1 G)
- 밤 보너스 게임 '모두의 온기'는 `night/assets/bgm_night.mp3`를 🔊 음소거 설정에 맞춰 게임 중에만 틀어요.
- 밤 온실 화면에도 배경음악이 있으면 좋겠어요. `sound.js`에 밤 테마를 추가해 주세요.
  - 화면: 밤 온실(장치 고르는 화면)
  - 분위기: 조용한 관제실, 느린 신스 패드 + 작은 반짝임(별), 템포 70~80, 단조 느낌이지만 무섭지 않게
  - 음량: 낮 온실 음악보다 조금 작게

## 4. 대시보드 점수 · 명예의 전당
- 모둠 카드에 **밤 점수(최고 100점)**도 보이면 좋겠어요. 계산은 `night/index.js`의 `nightScore(team)`를 그대로 불러 쓰면 돼요.
  - `import { nightScore } from './night/index.js'` → `nightScore(team)` → `{total, locks, bonus, tier, …}`
- 구역 줄(zoneRow)의 밤 칸 아이콘: LOCK 4 📦 · LOCK 5 ⚖️ · LOCK 6 🩺 · LOCK 7 🛡️ · LOCK 8 📝 · 보너스 🤲
- 명예의 전당에 밤 게임을 넣는다면: 키 `warmth`, 이름 '모두의 온기' (기록: 손을 올린 연구원 수, 걸린 시간)

## 5. 서버 확인 (1-1 K) — 바꿀 것 없음
- LOCK 8 '연구소장 승인'은 기존 `api/verify.js`의 **`night` 관리코드**로 확인해요 (`checkCode('night', code)`). 새 PIN·서버 변경이 필요 없어요.

## 6. 타이머
- 밤 제한 시간: **35분** (`config.js` `missionMinutes.night` 기본값 그대로)

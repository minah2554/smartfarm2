# 스마트팜 바이오 랩 : DAY & NIGHT — 웹앱 2번째 (온실 탐사형)

중2 과학 Ⅳ. 식물과 에너지 · 2022 개정 [9과12-01]~[9과12-03] (활동지와 동일)

현재 범위: **초기 화면(반·모둠 설정) + 낮 모드 + 관리자(관제 센터)**. 밤 모드는 대기 화면만 있습니다.

## 실행 방법
ES 모듈을 쓰기 때문에 파일을 더블클릭(file://)하면 열리지 않아요. 둘 중 하나로 여세요.
- 내 컴퓨터: 이 폴더에서 `npx serve .` 또는 VS Code **Live Server**
- 배포: Netlify / Vercel / GitHub Pages에 폴더째 올리기

## 화면 흐름
1. 시작 화면 → 반·모둠 선택 → 입장
2. 낮/밤 **토글 스위치** → 비밀번호 입력 → 입장
3. 처음 입장 시 FARM-OS 긴급 통신(스토리 브리핑 5장) — 화면 위 `브리핑`으로 다시 보기
4. 온실 장면: 땅속 H₂O 중 **색이 다른 분자 1개**, 공기 중 CO₂ 중 **색이 다른 분자 1개**, 햇빛 입자 중 **보라색 1개**를 누르면 암호 입력·힌트 창
5. 장치를 복구하면 연결된 시설물(물뿌리개·공구 창고·조명 제어판)에서 보너스 게임이 열림
6. 세 장치 복구 → 식물 성장(새싹→줄기→꽃봉오리→꽃) → 이름 짓기·이미지 저장
7. 관리자: 시작 화면 아래 `관제 센터` → 관리자 비밀번호 → 모둠 진행 현황(모니터 크게 보기)

## 선생님이 고치는 파일
| 파일 | 내용 |
|---|---|
| `config.js` | 반 수, 모둠 수, 낮·밤·관리자 비밀번호, 공유 방식 |
| `content.js` | 미션 정답·문구, 브리핑 스토리, FARM-OS 대사, 보너스 게임 설정 |
| `hints.js` | 1·2·3단계 힌트 (3단계는 1·2단계를 연 뒤에만 열림) |
| `scene.js` | 분자 위치(좌표)와 색이 다른 분자 번호 |

정답: LOCK1 `9C4E2R0` · LOCK2 `4K7L29` · LOCK3 기준카드 `OOOX` → 최종 `7294`

## 여러 태블릿 진행 상황을 한 모니터에 띄우기 (선택)
기본값 `sync.mode: 'local'`은 **같은 브라우저 안에서만** 공유돼요(미리보기용).
태블릿 여러 대를 교실 모니터에 모으려면:
1. Firebase 콘솔에서 프로젝트 생성 → Realtime Database 만들기
2. 규칙 예시(수업 기간에만 열어 두기 권장)
   ```json
   { "rules": { "smartfarm": { ".read": true, ".write": true } } }
   ```
3. `config.js` → `sync: { mode: 'firebase', firebaseDatabaseURL: 'https://○○○.firebasedatabase.app' }`
4. 수업 뒤 관제 센터의 `모든 모둠 기록 지우기`로 정리

Firebase 요금제·규칙 화면은 바뀔 수 있으니 콘솔에서 확인 필요.

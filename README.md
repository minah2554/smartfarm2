# 스마트팜 바이오 랩 : DAY & NIGHT — 웹앱 2번째 (온실 탐사형)

중2 과학 Ⅳ. 식물과 에너지 · 2022 개정 [9과12-01]~[9과12-03] (활동지와 동일)

현재 범위: **처음 화면(연구원 출입증) + 브리핑(낮·밤 공통) + 낮 구역 + 교사용 대시보드**. 밤 구역은 '준비 중' 화면만 있어요 (`config.js`의 `nightEnabled`).

## 실행 방법
ES 모듈을 쓰기 때문에 파일을 더블클릭(file://)하면 열리지 않아요.
- 내 컴퓨터: 이 폴더에서 `npx serve .` 또는 VS Code **Live Server**
- 배포: Netlify / Vercel / GitHub Pages에 폴더째 올리기

## 수업 흐름
1. **연구원 출입증**: 학년·반·모둠 선택 → 대표 연구원(팀장)·연구원(팀원) 이름 → 낮/밤 토글 → 비밀번호 → 입장
   - 입장하는 순간 **35분 카운트다운** 시작 (구역마다 따로)
   - 같은 학년·반·모둠으로 다시 입장하면 이름이 자동으로 채워지고 기록·타이머가 이어져요
2. **작전 브리핑**(모둠당 처음 한 번): 낮·밤 두 구역 상황 + 우리 모둠의 첫 투입 구역
3. **낮 구역**: 색이 다른 분자 → 암호·힌트 / 시설물 → 보너스 게임
4. **🏠 처음으로** 버튼: 언제든 처음 화면으로 (기록 저장, 타이머는 계속 흘러요)
5. **마무리**
   - 장치 3개 + 보너스 3개 모두 완료 → 식물 이름표 꽂기 → 실제 꽃 화분 사진(무작위) + 인증서
   - 시간 종료 → 키운 단계까지의 화분 그림으로 인증서 (이름 짓기 없음)
   - 인증서에는 등급, 연구원 이름, 완료 시간 또는 진행도, 힌트 사용 수가 들어가요

## 선생님이 고치는 파일
| 파일 | 내용 |

| `config.js` | 학년·반·모둠 수, 팀원 칸 수, 제한 시간(분), 비밀번호, 밤 구역 사용 여부, 저장 방식 |
| `content.js` | 출입증·브리핑 문구, 미션 정답, FARM-OS 대사, 보너스 게임(숨은 물건 목록·시간), 인증서 등급, 사진 목록 |

| `photos/` | 꽃이 핀 화분 사진 (`flower-01.jpg` ~ `flower-06.jpg`). 없으면 그림 화분으로 대신해요 |

## Firebase 연결 (여러 기기 · 실시간 대시보드)
`local` 모드에서는 **이 기기 안에서만** 기록이 이어져요. 다른 태블릿에서 같은 모둠으로 이어 하거나, 교실 모니터에 실시간으로 띄우려면:
1. Firebase 콘솔 → 프로젝트 만들기 → **Realtime Database** 만들기
2. 규칙 예시 (수업 기간에만 열어 두고, 끝나면 다시 잠그기 권장)
   ```json
   { "rules": { "smartfarm": { ".read": true, ".write": true } } }
   ```
3. `config.js` → `sync: { mode: 'firebase', firebaseDatabaseURL: 'https://○○○-default-rtdb.asia-southeast1.firebasedatabase.app' }`
4. 수업 뒤 대시보드에서 `모든 모둠 기록 지우기` (두 번 눌러야 지워져요)

- 대시보드는 Firebase 실시간 스트림으로 바로 갱신되고, 남은 시간은 1초마다 움직여요.
- 남은 시간은 서버 시각 기준이라 기기마다 시계가 달라도 같아요.
- 와이파이가 잠깐 끊겨도 기록은 기기에 모아 두었다가 다시 보내요.
- Firebase 요금제·콘솔 화면은 바뀔 수 있으니 확인 필요.

## 저장되는 데이터
학년·반·모둠, 대표 연구원·연구원 이름(학생이 입력), 해결한 장치·보너스, 연 힌트 단계, 시작·완료 시각, 식물 이름.
학번은 받지 않아요. 이름은 **성 빼고 이름만** 또는 별명으로 쓰게 하면 더 안전해요. 수업이 끝나면 기록을 지워 주세요.

밤 구역을 붙일 때: 기록의 `night` 칸(`night/startedAt`, `night/done/{미션}`, `night/finishedAt`)을 채우면 대시보드의 🌙 줄이 자동으로 움직여요.
